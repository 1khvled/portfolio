## 🛠️ Architecture & Modern Web Principles

- **Zero-Dependency Core:** Loads in sub-50ms with 100/100 Lighthouse performance metrics.
- **CSS Cascade Layers:** Modern `@layer reset, base, theme, components, utilities` architecture.
- **Accessible & Screen-Reader Compliant:** Built-in `.visually-hidden` utilities, landmark elements, full keyboard navigation and focus rings.
- **Instant Client-Side Filtering:** Zero latency category switching and live keyword search.
- **Vercel Edge Global CDN:** Clean routing, HTTP security headers, and edge caching via `vercel.json`.
